Baseline supervised pipeline on the TotalSegmentator dataset.

## Preprocessing (`nnUNetPlans_3d_fullres/`)

~47 GB total. Each subject produces three files:

| File | Format | Shape | Content |
|---|---|---|---|
| `s{ID}.b2nd` | Blosc2 float32 | `(1, D, H, W)` | CT, HU-clipped & z-normalized |
| `s{ID}_seg.b2nd` | Blosc2 int16 | `(1, D, H, W)` | Multi-label mask; **`-1` = ignore** |
| `s{ID}.pkl` | Pickle | — | Affine, spacing, bounding box, `class_locations` |

**Ignore label (`-1`)**: voxels excluded from Dice + CE loss. Present wherever a subject doesn't have a structure annotated (e.g. a pelvis-only scan has no brain/lung labels).

**`class_locations`** in `.pkl`: foreground voxel coordinates per class, used by nnUNet's patch sampler to guarantee 33% foreground patches during training.

**Intensity normalization** (`CTNormalization`): clips to global percentiles across the 1228-subject fingerprint (p0.5 = −1007 HU, p99.5 = +1573 HU), then z-score normalizes (global mean ≈ −167 HU, std ≈ 506 HU).

## Augmentations

### Patch sampling
Patches are extracted at `initial_patch_size` (slightly larger than 224³ to give rotation headroom), then the spatial transform crops back to 224³. **33% foreground oversampling**: with batch size 2, one patch is always centered on a foreground voxel (using `class_locations` from `.pkl`).

The 224³ isotropic patch has aspect ratio 1.0, which is below the anisotropy threshold of 3 → full 3D augmentation (no dummy-2D mode).

### Training transforms (applied in order)

| Transform | Probability | Parameters |
|---|---|---|
| **SpatialTransform** — rotation | p=0.2 | ±30° per axis (all 3) |
| **SpatialTransform** — scale | p=0.2 | ×0.7–1.4, isotropic |
| **SpatialTransform** — elastic | — | **disabled** (p_elastic=0) |
| **GaussianNoise** | p=0.1 | variance ~ U(0, 0.1) |
| **GaussianBlur** | p=0.2 | σ ~ U(0.5, 1.0) |
| **MultiplicativeBrightness** | p=0.15 | multiplier ~ U(0.75, 1.25) |
| **Contrast** | p=0.15 | contrast ~ U(0.75, 1.25), range preserved |
| **SimulateLowResolution** | p=0.25 | downsample scale ~ U(0.5, 1.0), then upsample |
| **Gamma** (with inversion) | p=0.1 | γ ~ U(0.7, 1.5) |
| **Gamma** (no inversion) | p=0.3 | γ ~ U(0.7, 1.5) |
| **MirrorTransform** | p=0.5/axis | axes (0, 1, 2) independently |
| **RemoveLabelTransform** | always | converts ignore=-1 → background=0 |

All intensity transforms operate on the normalized CT (post z-score), not raw HU.

### Validation transforms

Only `RemoveLabelTransform(-1 → 0)` + deep supervision downsampling. No spatial or intensity augmentation.

### Test-time inference

Sliding window with 50% tile overlap, Gaussian weight map for patch aggregation. **Mirror TTA** on all 3 axes (`use_mirroring=True`) — averages predictions over all 8 flip combinations.

### Comparison with patch_icl augmentations

| | nnUNet | patch_icl (`configs/augmentations.yaml`) |
|---|---|---|
| Rotation | ±30° (p=0.2) | ±15° task-aug (p=0.8), ±25° synth-aug (p=0.8) |
| Scale | ×0.7–1.4 (p=0.2) | ×0.85–1.15 task / ×0.9–1.5 synth |
| Elastic | disabled | p=0.3 task / p=0.8 synth |
| Flip | 3 axes (p=0.5 each) | 3 axes (p=0.5 each) |
| Gaussian noise | p=0.1 | p=0.5 |
| Gaussian blur | p=0.2 | p=0.5 |
| Brightness/contrast | p=0.15+0.15 | p=0.5 |
| Gamma | p=0.1+0.3 | p=0.3 |
| Low-res simulation | p=0.25 | not used |
| Scope | per-volume independent | task-aug: shared params across all K+1 volumes |

The key structural difference: patch_icl applies **task-level geometric augmentation** (same random params to target + all K context volumes) to keep the task consistent, then **independent intensity aug** per volume to add intra-task diversity. nnUNet augments each patch independently.

## Relationship to patch_icl — detailed comparison

nnUNet is the **standard supervised upper-bound**: one model, all 30 classes jointly, full 1.5 mm resolution, 224³ patches.

`ResEncInContext3D` borrows the same encoder family (nnUNetResEncM blocks via `ResidualEncoderUNet.encoder`) but differs in every other dimension:

| | nnUNet 3d_fullres | ResEncInContext3D |
|---|---|---|
| Stages | 6 | 4 |
| Features | `[32, 64, 128, 256, 320, 320]` | `[32, 64, 128, 256]` |
| Volume size | 224³ at 1.5 mm | 64³ (or 128³) |
| Encoder input | 1 channel (image) | 2 channels (image + mask) |
| Output | 31-class logits | Binary (foreground / background) |
| Mechanism | Standard supervised | In-context: target + K context pairs |
| Bottleneck | Convolutional decoder | Transformer (RoPE self-attn + cross-attn to context) |

## patch_icl pipeline in detail

### Intensity normalization

Fixed HU window `[−500, +1000]` → linear rescale to `[0, 1]`, stored as **float16** (halved disk footprint).

This differs from nnUNet's `CTNormalization` in three ways:
- **Fixed vs. data-driven window**: patch_icl uses a hard-coded window; nnUNet clips to per-dataset percentiles (−1007 / +1573 HU here) then z-scores.
- **Narrower range**: the patch_icl window clips bone above 1000 HU and excludes air below −500 HU. nnUNet's window is wider (−1007 to +1573 HU), capturing more of cortical bone and very dense implants.
- **Value space**: patch_icl values are always in [0, 1]; nnUNet values are in z-score space (approx. [−2, +2] for typical HU).

### Resolution strategy — whole-volume resize vs. patch extraction

This is the most fundamental spatial difference:

| | nnUNet | patch_icl |
|---|---|---|
| Strategy | 224³ crops from full native volume | Entire volume resized to 64³ |
| Effective resolution | ~1.5 mm (native) | ~4 mm at 64³ (1.5 × 231 / 64) |
| FoV per sample | Partial organ crop | Full body cross-section |
| Fine detail | High | Lost below ~3 voxels |
| Global organ context | None (crop) | Present (whole volume) |

The resize is done **once offline** by `scripts/convert_to_npy.py` using `scipy.ndimage.zoom(order=1)` for CT and `order=0` for labels. The dataloader fast path mmap-loads these pre-resized arrays directly — no computation at `__getitem__` time. The slow path (fallback when `.npy` absent) uses `torch.nn.functional.interpolate(trilinear/nearest)`, which can produce slightly different results for the same target size.

### Sample construction

Each training item is a **binary segmentation task for one class**:

```
target_img    (1, 64, 64, 64)   — query CT, normalized [0,1]
context_in    (K, 1, 64, 64, 64) — K context CTs (same class, different subjects)
context_out   (K, 64, 64, 64)   — K context binary masks
label         (64, 64, 64)       — target binary mask (ground truth)
```

nnUNet by contrast predicts all 30 classes in one forward pass from a single volume crop, with no context volumes.

### Missing-annotation handling

- **nnUNet**: uses the ignore label `−1`. A pelvis-only scan contributes all its annotated voxels to the loss; brain/lung voxels are masked out with `−1` so they neither contribute correctly-labelled signal nor penalise the model. Missing labels are invisible to the loss.
- **patch_icl**: uses the scan cache to build `label_to_subjects[cls]`. A subject is simply absent from that list if the class has no foreground voxels — it can never be sampled for that class. There is no ignore-label mechanism; out-of-bounds mask voxels after augmentation are treated as background (zeros padding), which is incorrect for structures near the volume boundary.

### Class-balanced sampling

With `class_balanced=True`, the sampler draws a class uniformly, then a subject for that class. This prevents large-anatomy classes (hip, femur) from dominating training, which they would if sampling were uniform over `(subject, class)` pairs. nnUNet's foreground oversampling is class-agnostic (33% foreground, any class).

### Synth augmentation path (no nnUNet equivalent)

`p_synth=0.5` means half of all training items come from the **synthetic supervoxel path** rather than real anatomy. One supervoxel is selected, then K+1 independent copies are created, each with heavy independent geometric + intensity augmentation applied. This is inspired by MultiverSeg and requires zero real segmentation annotations.

Four supervoxel algorithms are supported: `grid`, `watershed`, `slic`, `seeds3d`. The default is `slic` with union labels (adjacent supervoxels merged, producing organ-sized blobs). `n_segments` is drawn from U[50, 500] per subject.

### Augmentation scope — the critical difference

nnUNet augments each volume independently. patch_icl must maintain spatial correspondence between target and context, so:

1. **Task aug** (`apply_task_aug`): one shared set of geometric params (flip, affine, elastic) applied to all K+1 volumes via a single `F.affine_grid` call. This preserves the relative layout between target and context — if the model is learning to localize a liver, rotating everything 15° together keeps the task consistent.
2. **Intensity aug** (`apply_intensity_aug`): independent params per volume, to increase intra-task visual diversity without breaking spatial correspondence.
3. **Synth aug** (`apply_synth_aug`): fully independent per copy — the point is to make K+1 views of the same supervoxel look as different as possible.

### Augmentation parameters side-by-side

| Transform | nnUNet | patch_icl task | patch_icl synth |
|---|---|---|---|
| Flip | p=0.5/axis, all 3 | p=0.5/axis, all 3, **shared** | p=0.5/axis, independent |
| Rotation | ±30°, p=0.2 | ±15°, p=0.8, **shared** | ±25°, p=0.8, independent |
| Scale | ×0.7–1.4, p=0.2 | ×0.85–1.15, p=0.8, **shared** | ×0.9–1.5, p=0.8, independent |
| Translation | via crop headroom | ±10% volume, p=0.8 | ±20% volume, p=0.8 |
| Elastic | disabled | α=0.12 (norm. coords), p=0.3 | α=1–10 vox, σ=8–15 vox, p=0.8 |
| Gaussian noise | std up to 0.316, p=0.1 | std up to 0.05, p=0.5 | mean ±0.05, std ±0.05, p=0.5 |
| Gaussian blur | σ=0.5–1.0, p=0.2 | σ=0.5–1.5, p=0.5 | σ=0.1–1.5, p=0.5 |
| Brightness | ×0.75–1.25, p=0.15 | ±0.10 additive, p=0.5 | ±0.10 additive, p=0.5 |
| Contrast | ×0.75–1.25, p=0.15 | ×0.80–1.20, p=0.5 | ×0.5–1.5, p=0.5 |
| Gamma | γ=0.7–1.5, p=0.1+0.3 | γ=0.70–1.50, p=0.3 | — |
| Sharpness | — | — | unsharp mask ×5.0, p=0.5 |
| Low-res simulation | p=0.25 | — | — |

Two notable asymmetries:
- **Probability vs. magnitude**: patch_icl uses much higher application probabilities (p=0.8 for geometric) but tighter ranges; nnUNet uses lower probabilities but wider ranges. Net effect is likely similar expected deformation.
- **Elastic**: disabled in nnUNet; active in patch_icl. The synth path is much heavier (full Gaussian displacement field vs. the simple small-grid approach in task aug).

### Border / out-of-bounds handling during augmentation

| | Image | Mask |
|---|---|---|
| nnUNet | nearest edge replication | fills with −1 (→ ignore label, excluded from loss) |
| patch_icl | border replication (`padding_mode="border"`) | fills with 0 (background, included in loss as TN) |

The nnUNet convention is strictly correct — out-of-bounds voxels after rotation genuinely have unknown labels and should be ignored. patch_icl's zero-fill treats them as confirmed background, which is usually benign for central structures but can introduce false negatives near the crop boundary.

### Loss and deep supervision

- **nnUNet**: Dice + CE with deep supervision (loss at each decoder scale, exponentially downweighted). Dice is sample-level.
- **patch_icl**: Dice + CE, no deep supervision, single output head.

### Inference

- **nnUNet**: sliding window (50% overlap, Gaussian aggregation), mirror TTA over all 8 flip combinations.
- **patch_icl**: single forward pass on the full 64³ volume. No sliding window, no TTA implemented.
