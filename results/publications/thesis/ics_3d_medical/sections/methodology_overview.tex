\subsection{Problem Setup and Backbone}\label{sec:methodology-overview}

We use the setting of \autoref{sec:fundamentals-icl}: given a target volume
$I^t$ and $K$ context pairs $(I^c_k, L^c_k)$ showing the same class, the model
predicts the target mask $\hat{L}^t$. Prediction runs through a cascade of $M$
levels with decreasing voxel spacing $r_1 > r_2 > \dots > r_M$. Each level
predicts a mask, which is passed to the next level as a prior
(\autoref{sec:methodology-cascade}). Within a level, the model consists of a
shared encoder, a stack of dual attention layers, and a decoder
(\autoref{fig:overview}). Medverse's architecture is shown for comparison in
\autoref{fig:overview-medverse} in the appendix.

\paragraph{Shared encoder.}
All $K+1$ images of a task pass through the same encoder, which produces a
feature pyramid for each. The encoder sees only images; masks enter the model
through the label tokens described below. We read out two disjoint sets of
encoder stages. The coarse stages are resampled to a common
$R \times R \times R$ grid, giving $N = R^3$ cells per volume, and form the
input to the attention layers. The fine stages keep their native resolution and
serve as skip connections for the decoder (\autoref{sec:methodology-fusion}).
The attention layers therefore always operate on a small grid of fixed size,
while the decoder can still produce a full-resolution mask.

\paragraph{Tokens.}
Each cell of each volume is represented by two tokens: an image token
$z^{\text{img}}$, computed from the coarse encoder features at that cell, and a
label token $z^{\text{lbl}}$, an embedding of the mask at that cell. For a
context volume, the label token embeds the ground-truth mask $L^c_k$. For the
target, the mask is unknown: at the first cascade level its label tokens are
initialized with a placeholder, and at later levels with the previous level's
prediction (\autoref{sec:methodology-cascade}). Learned embeddings mark each
token as belonging to the target or to a context volume. A small number of
learned register tokens, shared across volumes, are appended to the sequence.
They are not tied to any cell and give the attention layers a fixed amount of
global memory.
